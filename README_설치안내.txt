하루계획 — 아이패드용 일정 관리 웹앱 (PWA)
======================================
이 앱은 크롬 확장 프로그램이 아닙니다. 아이패드의 Safari에서 홈 화면에 추가하는 웹앱입니다.

[들어 있는 파일]
- index.html : 일정 관리 화면과 전체 기능
- manifest.webmanifest : 웹앱 설치 정보
- service-worker.js : 처음 접속한 뒤 오프라인 실행을 돕는 파일
- icon-192.png, icon-512.png, apple-touch-icon.png : 홈 화면 아이콘 3개
- README_설치안내.txt : 현재 안내문 (업로드하지 않아도 됨)

[아이패드만으로 설치하기 — GitHub Pages 무료 이용]
1. 아이패드의 '파일' 앱에서 ZIP 파일을 탭해 압축을 풉니다.
2. Safari에서 https://github.com 에 접속해서 가입 또는 로그인합니다.
3. 우측 상단 + > New repository(새 저장소)를 눌러 저장소 이름을 'my-ipad-planner'로 정하고 Public으로 만듭니다.
   편의를 위해 'Add a README file'을 체크하고 Create repository를 누릅니다.
4. 저장소 화면에서 'Add file' > 'Upload files'를 눌러 압축 해제한 폴더의 파일 6개를 업로드합니다.
   index.html / manifest.webmanifest / service-worker.js / icon-192.png / icon-512.png / apple-touch-icon.png
   (README_설치안내.txt는 선택적으로 업로드하고, .nojekyll은 보이면 함께 업로드하세요.)
   중요: 6개 파일은 하위 폴더가 아닌 저장소의 맨 위(root)에 놓아야 합니다.
5. 'Commit changes'로 저장합니다.
6. 저장소의 Settings > Pages에서 Source를 'Deploy from a branch'로 바꾼 후
   Branch: main, Folder: /(root)를 선택하고 Save를 누릅니다.
7. 게시가 완료되면 다음 주소에서 열립니다.
   https://내_깃허브_아이디.github.io/my-ipad-planner/
8. 아이패드 Safari에서 해당 URL을 연 다음 공유 버튼 > '홈 화면에 추가' > '웹 앱으로 열기' 활성화 > 추가.
   이제 홈 화면의 '하루계획' 아이콘으로 실행합니다.

[사용 방법]
- '+ 새 일정 추가'로 제목/날짜/시간/분류/중요도/메모를 저장합니다.
- 일정의 네모 체크박스를 누르면 완료/미완료가 전환됩니다.
- '수정' '삭제' 버튼으로 일정을 관리합니다.
- 달력의 날짜를 누르면 그날 일정만 볼 수 있습니다.
- 상단 필터와 검색으로 일정을 좁혀 볼 수 있습니다.
- '백업 파일 저장'으로 JSON 파일을 내려받고 '백업 불러오기'로 복원합니다.
- CSV 내보내기로 스프레드시트에서 사용할 수 있는 목록을 받습니다.

[매우 중요한 주의사항]
- 일정은 GitHub에 전송되지 않고 사용 중인 기기의 해당 웹앱/브라우저 저장소에만 저장됩니다.
- 아이패드 Safari와 홈 화면에 설치한 앱의 저장 공간이 분리되거나 다르게 취급될 수 있으니
  처음부터 홈 화면 아이콘을 통해 입력하고 사용하세요.
- 앱 삭제, 사이트 데이터 삭제, 브라우저 데이터 정리, 일부 기기 환경에 따라 저장 내용이 사라질 수 있습니다.
- 기기 간 실시간 동기화, 서버 백업, 일정 알림/푸시 알림 기능은 없습니다.
- 데이터가 중요하다면 '백업 파일 저장'을 주기적으로 사용하세요.
- 최초 설치를 위해 인터넷 연결이 필요합니다. 최초 정상 접속 후에는 오프라인 사용을 지원합니다.
- 소스 파일을 GitHub의 공개 저장소에 올려도, 개인 일정 자체는 업로드되지 않습니다.

[설치가 어려운 경우]
GitHub 업로드와 Pages 설정은 웹사이트 화면에 따라 명칭이나 배치가 다를 수 있습니다.
파일 경로가 정확히 유지되는지 먼저 확인해주세요.
